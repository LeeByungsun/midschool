# 학교도우미 iOS

이 폴더는 학교도우미의 iPhone용 앱 작업 공간입니다.

현재 단계:

- iOS 전용 스펙 문서 추가
- SwiftUI 기반 폴더 골격 생성
- 화면/도메인 구조 초안 정리
- shared app/widget storage 및 widget snapshot foundation 추가
- `SchoolHelperWidget` WidgetKit source/target scaffold 추가
