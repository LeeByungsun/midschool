# Android UI Refresh Mockup

이 문서는 **코드 수정 없이** 현재 Android 앱 화면을 더 보기 좋게 다듬기 위한 **시안(mockup)** 정리본입니다.

## 범위

현재 Android 화면 구조를 기준으로 다음 화면의 개선 방향만 제안합니다.

- 홈 대시보드 (`android/app/src/main/res/layout/activity_main.xml`)
- 시간표 (`android/app/src/main/res/layout/activity_timetable.xml`)
- 학사 일정 (`android/app/src/main/res/layout/activity_schedule.xml`)
- 초기 설정 / 설정 (`android/app/src/main/res/layout/activity_setup.xml`, `activity_settings.xml`)

이번 작업에는 다음이 포함되지 않습니다.

- Kotlin / XML / 리소스 실제 반영
- 네비게이션 구조 변경
- 기능 추가 구현
- 문자열/데이터 계약 변경

## 목업 방향

### 1. 홈을 “정보 카드 모음”에서 “오늘의 학교 생활 대시보드”로 강화

현재 홈은 카드 단위 구성은 좋지만, 섹션 간 위계가 다소 평평합니다. 시안에서는 다음을 강조합니다.

- 상단을 **학교명 + 오늘 날짜 + 빠른 액션**이 있는 히어로 영역으로 통합
- 시간표 / 급식 / 일정 / 타이머를 **한 화면에서 우선순위 순서대로** 스캔 가능하게 정렬
- 정보 밀도는 유지하되, 카드별 색상 신호를 분명하게 부여
- 타이머는 하단 큰 카드로 유지하되 **프리셋 + 현재 상태 + CTA**를 더 명확하게 표현

### 2. 시간표 / 일정 상세는 “탐색”보다 “당일 확인”에 집중

- 날짜 이동 버튼을 더 시각적인 칩/세그먼트 느낌으로 정리
- 교시 정보는 줄글보다 **개별 레슨 카드**로 전환한 느낌을 사용
- 당일 상태(몇 교시, 실시간 확인 포인트)를 상단 요약 카드에 분리
- 학사 일정은 월 이동보다도 **이번 주 / 이번 달 주요 일정**이 먼저 읽히도록 구성

### 3. 설정 / 초기 설정은 단순 폼보다 “단계형 설정 경험”으로 정리

- 학교 검색 → 학교 선택 → 학년/반 입력 → 저장을 시각적으로 더 명확하게 분리
- 선택된 학교를 텍스트 한 줄 대신 **요약 카드**로 강조
- 타이머 옵션은 스위치 나열 대신 **카테고리 블록**으로 묶어 가독성 개선

## 비주얼 시스템 제안

현재 색상 자산을 최대한 유지하면서 톤만 더 세련되게 쓰는 방향입니다.

- 메인 배경: 아주 옅은 블루 그레이 (`bg_page` 계열 유지)
- 핵심 포인트: 기존 `brand_navy`, `brand_blue` 중심 유지
- 강조 카드: 블루 / 민트 / 옐로우 톤을 용도별로 구분
- 카드 반경: 현재 24~28dp 감성을 유지하되 그림자와 내부 간격을 조금 더 명확히 사용
- 텍스트 위계:
  - 화면 제목 28sp 수준 유지
  - 카드 제목 18sp
  - 요약 숫자/카운터는 32~40sp 강조
  - 보조 설명은 13~15sp 범위 유지

## 화면별 요약

### 홈

- 상단 히어로 카드 안에
  - 학교명
  - 오늘 날짜
  - 학년/반 요약
  - 빠른 설정 버튼
  - 오늘 핵심 요약 칩
- 시간표 카드는
  - 오늘 과목 흐름
  - 남은 교시/다음 수업
  - 시간표 열기 버튼
- 급식 카드는
  - 오늘 급식 상태 배지
  - 메뉴 텍스트
  - 칼로리/특이식품 같은 메타가 필요하면 하단 보조 줄 추가 가능
- 일정 카드는
  - 다가오는 일정 2~3건을 리스트로 보여주고
  - “전체 일정 보기” CTA 유지
- 타이머 카드는
  - 현재 집중 모드 / 남은 시간 / 프리셋 / 시작 버튼을 한 카드 안에 정리

### 시간표

- 날짜 헤더를 상단 강조 카드로 유지
- 이전/다음 날짜 이동은 pill 버튼 느낌으로 통일
- 과목 목록은 교시 번호별 카드 리스트로 정돈
- 빈 상태/에러 상태도 동일 카드 레이아웃 안에서 처리 가능하게 설계

### 일정

- 월 이동 컨트롤은 유지
- 본문은 긴 텍스트 대신
  - 날짜 배지
  - 일정 제목
  - 중요 일정 강조 색상
  형태의 리스트 카드가 더 적합

### 설정 / 초기 설정

- 검색 입력과 버튼을 한 덩어리로 묶고
- 선택된 학교는 별도 카드로 강조
- 학년/반 입력은 두 칸 그리드 느낌으로 단순화 가능
- 저장 버튼은 하단 고정 CTA처럼 보이게 처리 가능
