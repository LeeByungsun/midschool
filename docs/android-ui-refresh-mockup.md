# Android UI 리프레시 목업 메모

이 문서는 2026-05-19 기준으로 Android 앱 UI를 더 보기 좋게 다듬기 위한 **목업 전용 제안서**입니다.  
이번 작업은 **코드 수정 없이** 현재 화면 구조를 검토하고, 다음 구현 단계에서 참고할 수 있는 시각 방향과 화면별 와이어프레임을 문서화하는 데 목적이 있습니다.

## 검토 범위

- `android/app/src/main/res/layout/activity_main.xml`
- `android/app/src/main/res/layout/activity_setup.xml`
- `android/app/src/main/res/layout/activity_settings.xml`
- `android/app/src/main/res/layout/activity_timetable.xml`
- `android/app/src/main/res/layout/activity_schedule.xml`
- `android/app/src/main/res/values/colors.xml`
- `android/app/src/main/res/values/strings.xml`
- `web/components/app-page.tsx`
- `web/components/dashboard-card.tsx`
- `web/components/home-dashboard.tsx`

## 현재 UI에서 보이는 강점

- 홈 화면이 이미 **카드 기반 정보 구조**를 가지고 있어 리디자인 출발점이 나쁘지 않습니다.
- `colors.xml` 기준으로 배경/카드/브랜드 컬러가 분리되어 있어, 큰 리브랜딩 없이도 완성도를 높일 수 있습니다.
- 시간표/급식/일정/타이머가 이미 분리되어 있어 정보 우선순위를 다시 정리하기 쉽습니다.

## 현재 UI에서 아쉬운 점

1. **홈 화면 세로 길이 과다**
   - 홈 상단 히어로, 급식, 일정, 타이머가 모두 같은 무게로 길게 쌓여 있습니다.
   - “오늘 가장 중요한 정보”가 한 번에 눈에 들어오지 않습니다.

2. **설정/초기 설정 화면의 폼 밀도 부족**
   - `activity_setup.xml`, `activity_settings.xml`은 기능은 충분하지만 시각적으로는 기본 폼 나열에 가깝습니다.
   - 입력/선택/저장 흐름이 한 덩어리로 보여서 완료감이 약합니다.

3. **상세 화면의 탐색 리듬이 단조로움**
   - 시간표/일정 화면 모두 정보는 잘 보이지만, 월/일 이동 컨트롤과 본문 카드의 위계가 평평합니다.
   - “현재 보고 있는 날짜/월”의 강조가 약합니다.

4. **액션 강조 방식이 제각각**
   - 어떤 곳은 버튼, 어떤 곳은 카드, 어떤 곳은 텍스트 배경으로 처리되어 UI 톤이 완전히 통일되지는 않습니다.

## 제안 방향

핵심 방향은 **“학생용 오늘의 대시보드”** 느낌을 강화하는 것입니다.

- 홈은 “오늘 정보 요약 → 핵심 카드 3개 → 타이머” 순서로 재구성
- 설정은 “단계형 카드 폼”으로 정리
- 시간표/일정은 “날짜 강조 + 빠른 이동 + 요약 배지” 추가
- Android의 기존 블루 계열은 유지하되, 웹 대시보드처럼 **더 큰 여백 / 더 깊은 그림자 / 더 분명한 배지**를 사용

## 시각 시스템 제안

### 1) 컬러

현재 토큰을 최대한 재사용하되 역할을 더 분명히 나눕니다.

- 메인 배경: `bg_page`
- 기본 카드: `surface_card`
- 히어로/주요 CTA: `brand_navy`, `brand_blue`
- 상태 배지:
  - 성공/급식: `brand_green_soft`, `brand_green_text`
  - 오늘/강조: `brand_yellow_soft`, `brand_yellow_text`
  - 보조 안내: `brand_blue_soft`

### 2) 라운드/간격

- 상단 히어로 카드: 28~32dp radius
- 일반 카드: 24dp radius
- 칩/배지/필터: 16~18dp radius
- 화면 좌우 패딩: 20~24dp 유지
- 카드 간 간격: 12~16dp로 통일

### 3) 타이포

- 화면 타이틀: 28sp bold 유지
- 카드 타이틀: 18sp semibold/bold
- 상태 배지: 12~13sp bold
- 설명/보조 텍스트: 14~15sp

## 홈 화면 목업

### 의도

- 지금의 긴 세로 스크롤을 유지하되, 첫 화면에서 **학교/오늘/요약 상태**가 한 번에 보이도록 재배치합니다.
- 웹의 `AppPage`, `DashboardCard`처럼 카드 리듬을 더 분명하게 가져갑니다.

### 와이어프레임

```text
│ [일정 2개] [집중 40분]               │
│                                      │
│ 오늘 학교생활 요약                   │
│ "급식 정상 · 5교시 체육 준비 ·       │
│  방과후 상담 일정 있음"              │
```

### 변경 포인트

- 기존 상단 카드 안에 있던 “오늘의 학교생활” 요약을 **상단 히어로의 핵심 콘텐츠**로 승격
- 시간표/급식/일정 카드에 모두 **우측 상단 액션 라벨** 배치
- 타이머 프리셋은 현재처럼 카드형을 유지하되, 선택 상태 대비를 더 크게 표시

## 시간표 화면 목업

### 의도

- 날짜 전환 UI를 “탐색 도구”처럼 보이게 하고, 오늘 버튼을 더 분명한 상태 칩으로 강조합니다.
- 각 교시를 단순 텍스트 나열 대신 카드 리스트 느낌으로 정리합니다.

### 와이어프레임

```text
┌──────────────────────────────────────┐
│ ← 시간표                             │
│ 5월 19일 화요일                      │
│ 2학년 3반 · 총 7교시                 │
└──────────────────────────────────────┘

 [이전 날]                [다음 날]
 [오늘]

┌ 1교시 ─ 수학 ─────────────── 수업중? ┐
│ 준비물/메모가 있으면 보조 텍스트      │
└──────────────────────────────────────┘
┌ 2교시 ─ 영어 ───────────────────────┐
└──────────────────────────────────────┘
┌ 3교시 ─ 국어 ───────────────────────┐
└──────────────────────────────────────┘
```

### 변경 포인트

- 날짜 카드 상단에 요약 정보 집약
- 현재 `timetableContainer`에 들어가는 각 교시 항목을 **동일 높이 카드**로 보여주는 방향 권장
- 오늘 날짜일 때는 첫 교시 카드나 상단 배지에 노란 강조 사용

## 일정 화면 목업

### 의도

- 월 이동 텍스트 버튼을 더 명확한 필터/페이저로 보이게 만듭니다.
- 이번 달 일정 목록에서 중요한 일정이 더 잘 스캔되도록 날짜와 제목을 분리합니다.

### 와이어프레임

```text
┌──────────────────────────────────────┐
│ ← 학사 일정                          │
│ [이전 달]   2026년 5월   [다음 달]   │
└──────────────────────────────────────┘

┌ 이번 달 핵심 일정 3개                ┐
│ 05.19 상담주간 시작                  │
│ 05.21 체육복 착용                    │
│ 05.23 봉사활동 신청 마감             │
└──────────────────────────────────────┘

┌ 전체 일정                            ┐
│ 05.19  상담주간                      │
│ 05.21  체육복 착용                   │
│ 05.23  봉사활동 신청 마감            │
│ 05.27  동아리 발표                   │
```

### 변경 포인트

- 월 타이틀을 가운데 두되, 상단 전체를 하나의 탐색 바처럼 보이게 구성
- 일정이 많을수록 날짜 숫자 컬럼과 내용 컬럼을 분리해 가독성 강화

## 초기 설정 / 설정 화면 목업

### 의도

- 긴 폼을 “학교 선택 → 학년/반 → 저장”의 단계형 카드로 보여줘 완료감을 높입니다.
- 설정 화면은 단순 입력 페이지보다 **프로필 편집 화면**처럼 느껴지게 정리합니다.

### 와이어프레임

```text
┌ 처음 설정                           ┐
│ 학교 생활 정보를 정확히 보여주기 위해 │
│ 학교와 학년/반을 먼저 저장해 주세요. │
└──────────────────────────────────────┘

┌ 1. 학교 선택                         ┐
│ 학교 이름 입력                       │
│ [미사중학교____________________]      │
│ [학교 검색]                          │
│ 선택한 학교: 다원중학교 / 경기       │
└──────────────────────────────────────┘

┌ 2. 학생 정보                         ┐
│ 학년 [ 2 ]                           │
│ 반   [ 3 ]                           │
└──────────────────────────────────────┘

┌ 3. 시작 준비 완료                    ┐
│ 저장 후 홈에서 시간표/급식을 확인     │
│ 할 수 있어요.                        │
│ [시작하기]                           │
└──────────────────────────────────────┘
```

### 설정 화면 추가 제안

- 현재 저장된 학교/학년/반을 상단 요약 카드로 먼저 노출
- 타이머 표시 방식, 알림음, 진동은 **“타이머 설정” 묶음 카드**로 정리
- 저장 버튼은 맨 아래 고정 CTA처럼 보이도록 더 분명하게 강조

## 구현 시 우선순위 제안

코드 작업은 이번 범위가 아니지만, 실제 적용 시에는 아래 순서를 권장합니다.

1. **홈 화면 리듬 정리**
   - 정보 우선순위와 카드 여백만 조정해도 체감 개선 폭이 큼
2. **설정/초기 설정 카드화**
   - 기본 폼 화면의 완성도가 빠르게 올라감
3. **시간표 상세 항목 카드화**
   - 데이터는 그대로 두고 시각 밀도만 개선 가능
4. **일정 화면 탐색 바 정리**
   - 월 이동 UX가 더 자연스러워짐

## 이번 목업의 범위 밖

- Compose 전환
- 네비게이션 구조 변경
- 상태/데이터 로직 변경

## 한 줄 결론

현재 Android UI는 **정보 구조는 이미 괜찮고, 시각 위계와 화면 리듬만 다듬어도 훨씬 좋아질 상태**입니다.  
이번 목업은 기존 블루 계열 브랜드와 카드 구조를 유지하면서, 웹 대시보드에서 보이는 더 정돈된 카드 언어를 Android 쪽에 옮겨오는 방향을 제안합니다.
