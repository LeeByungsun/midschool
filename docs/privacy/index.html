스쿨온(이하 “앱”)은 학교 급식, 시간표, 학사 일정, 가정통신문, 집중 타이머 및 위젯 기능을 제공합니다. 이 방침은 앱에서 처리하는 정보, 선택 동의형 Firebase 분석·오류 진단, 이용자의 선택권을 설명합니다.

공개 전 확인: Firebase Analytics 보관 기간의 실제 설정값을 Firebase Console에서 확인해 이 문구와 Play Console의 데이터 보안 답변을 일치시키세요.

1. 처리하는 정보와 목적

앱 저장소에 보관하는 정보

이 정보는 운영자 계정 서버에 저장하지 않으며, 자녀 프로필을 담은 student_profiles 저장소는 Android 클라우드 백업과 기기 간 자동 전송에서 제외하도록 앱을 설정했습니다. 선택 동의 설정도 백업·기기 이전 대상에서 제외합니다.

앱은 계정, 생년월일, 전화번호, 이메일 주소, 광고 ID, Android ID, 기기 일련번호를 수집하거나 요구하지 않습니다. 자녀 프로필 이름은 사용자가 기기에 입력하는 로컬 표시 이름이며 외부 서버나 Firebase로 전송하지 않습니다.

학교 정보 조회

학교 검색 시 입력한 학교 검색어를 교육부/교육청의 나이스 교육정보 개방 포털 API에 전송합니다. 급식·시간표·학사 일정 조회 시에는 선택한 학교·교육청 코드, 조회 날짜 및 시간표 조회에 필요한 학년·반을 전송합니다. 가정통신문 조회 시에는 앱의 기존 웹 API(midschool.vercel.app, 실제 출시 URL 변경 시 갱신)에 학교·교육청 코드와 조회 건수를 전송합니다. 서비스 조회를 위한 통신 과정에서 각 서버는 IP 주소 등의 기술적 접속 정보를 자체 정책에 따라 처리할 수 있습니다.

선택 동의: 이용 정보 분석

이용자가 이용 정보 분석에 동의를 켠 경우에만 Firebase Analytics로 다음의 제한된 정보를 전송합니다.

  • 앱 진입 및 화면·기능·위젯 이용, 시간표·급식·일정·가정통신문 조회 결과, 타이머 동작
  • 조회 성공/실패, 데이터 출처(네트워크/캐시), 처리 시간, 정규화된 오류 코드
  • 교육청 코드, 학교 코드, 학교 종류, 초기 설정 완료 여부
  • 앱 실행 환경(릴리스/QA 등)

학교명, 자녀 이름, 프로필 ID, 학년, 반, 학교 검색어, API URL·응답 본문은 앱이 만든 Analytics 이벤트로 전송하지 않습니다. 앱은 광고 ID 권한과 광고 개인화 기능을 사용하지 않습니다. Firebase SDK는 분석을 위해 앱 설치 식별정보 등 자체 기술 정보를 처리할 수 있습니다.

선택 동의: 오류 진단

이용자가 오류 진단 정보 제공에 동의를 켠 경우에만 Firebase Crashlytics로 비정상 종료 및 제한된 비치명 오류 정보를 전송합니다. 이때 앱 버전, 제조사, 기기 모델, Android SDK 버전, 현재 화면, 교육청/학교 코드, 학교 종류, 초기 설정 완료 여부, 정규화된 오류 코드 및 기술적 오류 스택이 포함될 수 있습니다. Crashlytics는 오류를 묶어 분석하기 위해 Firebase 설치 ID, Crashlytics 설치 UUID 등 SDK 식별정보도 처리할 수 있습니다.

3. 선택 동의와 철회

Analytics와 오류 진단은 기본적으로 꺼져 있으며, 동의하지 않아도 학교 정보 조회와 타이머의 핵심 기능을 사용할 수 있습니다. 이용자는 언제든지 앱의 설정 → 선택 정보 수집 동의에서 각각 켜거나 끌 수 있습니다.

  • Analytics를 끄면 이후 앱의 분석 데이터 수집을 중지하고 기기에 보관된 Analytics 데이터를 초기화하도록 SDK에 요청합니다.
  • 오류 진단을 끄면 이후 진단 정보 수집을 중지하고, 아직 전송되지 않은 오류 보고서를 삭제하도록 SDK에 요청합니다. 자동 오류 보고 설정 변경은 다음 실행부터 적용될 수 있습니다.

이미 Firebase에 전송되어 보관 중인 정보의 삭제·보관은 Firebase Console 설정 및 Google 정책의 적용을 받을 수 있습니다.

4. 보관 및 파기

앱 저장 정보는 프로필별로 기기에 보관되며, 사용자가 프로필을 삭제하거나 앱 데이터 삭제·앱 삭제 시 기기에서 삭제됩니다. 프로필 저장소는 Android 백업·기기 이전에서 제외됩니다. Firebase Analytics의 이용자·이벤트 수준 데이터 보관 기간은 운영자가 Firebase Console에서 설정한 기간(현재 설정 확인 필요)입니다. Firebase Crashlytics는 Google의 현재 보관 정책에 따라 오류 스택과 관련 식별정보를 보관합니다. 이미 전송된 정보를 앱에서 동의를 끄는 것만으로 즉시 모두 삭제할 수는 없습니다.

5. 이용자의 권리와 문의

이용자는 앱 설정에서 선택 동의를 변경할 수 있고, Android 설정에서 앱 데이터 삭제 또는 앱 삭제로 기기 내 저장 정보를 삭제할 수 있습니다. 백업본은 해당 Android 백업 설정에서 관리해야 합니다. 개인정보 처리에 관한 문의, 열람·정정·삭제 요청은 위 문의처로 보내 주세요. 앱에는 회원 계정이 없으므로 계정 삭제 대상은 없습니다.

6. 아동·청소년 이용자

앱은 학생이 사용하기 쉬운 학교 정보 확인 도구입니다. 민감정보 또는 계정 기반 개인 프로필을 수집하지 않으며, 선택형 분석·진단 수집은 기본적으로 꺼져 있습니다. 보호자 또는 법정대리인의 권리 행사 문의는 위 문의처로 할 수 있습니다.

7. 방침 변경

이 방침이 변경되면 시행일과 변경 내용을 공개 페이지 및 앱 업데이트 안내에 표시합니다.
