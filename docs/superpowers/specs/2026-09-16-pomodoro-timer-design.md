# 포모도로 타이머 설계

## 목표
기존 단일 카운트다운을 집중·짧은 휴식·긴 휴식이 이어지는 사용자 설정형 포모도로 세션으로 확장한다. 사용자는 집중 시간, 짧은 휴식, 긴 휴식과 라운드 수(1~4회)를 설정할 수 있다.

## 사용자 흐름
- 기본값은 집중 25분, 짧은 휴식 5분, 긴 휴식 15분, 4라운드다.
- 설정 화면에서 각 시간을 1~120분 범위로 조정하고 라운드는 1~4회 중 선택한다.
- 한 구간이 끝나면 단말 모드에 맞춰 소리/진동을 한 번 실행하고 다음 구간 시작 버튼을 표시한다.
- 집중과 짧은 휴식을 설정 라운드만큼 반복한 뒤 긴 휴식 시작 버튼을 표시한다.
- 긴 휴식 완료 후 세션을 완료 상태로 만들고 새 세션 시작을 표시한다.
- 일시정지, 재개, 초기화가 모든 구간에서 동작한다.

## 상태 모델
`PomodoroPhase`는 `FOCUS`, `SHORT_BREAK`, `LONG_BREAK`를 가진다. 저장 상태에는 현재 phase, 완료한 focus round, 목표 시각, 실행 여부, 설정값이 포함된다. 앱 재실행 시 목표 시각으로 남은 시간을 복원하며 만료된 구간은 완료 대기 상태로 복원한다.

## UI
타이머 카드에 현재 단계(`집중 1/4`, `짧은 휴식 1/4`, `긴 휴식`)와 남은 시간을 표시한다. 구간이 완료되면 주 버튼은 `다음 휴식 시작`, `다음 집중 시작`, `긴 휴식 시작`, 또는 `새 세션 시작`으로 바뀐다. 기존 숫자/원형 표시 모드와 QA 1분 축약 동작은 유지한다.

## 비기능 요구
- 알림창/푸시 알림을 만들지 않는다. 완료 신호는 `TimerCompletionAlert`만 사용한다.
- 기존 저장 데이터가 없거나 형식이 오래된 경우 기본 포모도로 설정으로 안전하게 초기화한다.
- 상태 전이, 설정 범위, 복원, 라운드 경계는 단위 테스트로 검증한다.
