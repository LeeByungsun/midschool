# 학교생활도우미 정보 수집·이용 안내 (약식)

> 앱 설정 또는 처음 동의 화면에 보여줄 **간단한 안내문 초안**입니다. 공개 개인정보처리방침을 대체하지 않습니다. 최종 문서는 [`privacy-policy.ko.md`](privacy-policy.ko.md)입니다.

학교생활도우미는 로그인 없이 학교 급식, 시간표, 학사 일정, 가정통신문, 타이머와 위젯을 제공합니다.

| 구분 | 정보와 사용 목적 | 선택 여부 |
| --- | --- | --- |
| 앱 저장소 | 선택한 학교·교육청 코드, 학년·반, 타이머·위젯 설정, 조회 내용의 임시 저장: 화면 표시·복원 | 기능 이용에 필요 |
| 학교 정보 조회 | 학교 검색어를 나이스 API에, 학교·교육청 코드와 조회 날짜·필요한 학년·반을 나이스 API에 전송: 검색·급식·시간표·일정 조회 | 기능 이용 시 전송 |
| 가정통신문 조회 | 학교·교육청 코드와 조회 건수를 기존 앱 웹 API에 전송: 최근 가정통신문 표시 | 기능 이용 시 전송 |
| 이용 정보 분석 | Google Firebase Analytics에 앱 접속·기능 사용·조회 결과, 학교·교육청 코드, 학교 종류, 처리 시간·오류 코드, 설치 식별정보 등 | **기본 꺼짐, 별도 선택 동의** |
| 오류 진단 | Google Firebase Crashlytics에 오류 내역·화면, 학교·교육청 코드, 앱 버전·OS·기기 모델, Firebase/Crashlytics 설치 식별정보 등 | **기본 꺼짐, 별도 선택 동의** |

앱이 만든 분석·오류 이벤트에는 학교명, 학년·반, 학교 검색어, API 응답 내용, 광고 ID를 추가하지 않습니다. Firebase SDK와 각 조회 서버는 자체 기술 정보(IP 주소나 설치 식별정보 등)를 처리할 수 있습니다. 앱 정보 중 일부는 Android 백업/기기 이전 설정에 따라 백업될 수 있지만, 선택 동의 설정은 백업 대상에서 제외합니다.

선택 동의하지 않아도 핵심 기능을 사용할 수 있습니다. 동의는 **설정 → 선택 정보 수집 동의**에서 언제든지 바꿀 수 있습니다. 끄면 이후 수집이 중단되지만, 이미 전송된 데이터가 즉시 자동 삭제되는 것은 아닙니다. 기기 내 저장 정보는 앱 데이터 삭제 또는 앱 삭제로 지울 수 있습니다.

자세한 내용과 문의처는 공개 [개인정보처리방침](privacy-policy.ko.md)을 확인해 주세요.
