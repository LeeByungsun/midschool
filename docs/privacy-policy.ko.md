# 학교생활도우미 개인정보처리방침

- **시행일:** 2026년 9월 15일
- **앱 운영자:** 학교생활도우미 운영자
- **문의처:** **[출시 전 운영자 이메일 주소를 입력하세요]**

학교생활도우미(이하 “앱”)는 학교 급식, 시간표, 학사 일정 및 집중 타이머 기능을 제공합니다. 이 방침은 앱에서 처리하는 정보, 선택 동의형 Firebase 분석·오류 진단, 이용자의 선택권을 설명합니다.

> 출시 전 필수 입력: 문의처 이메일, 실제 공개 URL, Firebase Console의 데이터 보관 기간을 확인하여 이 문서와 Play Console의 Data safety 답변을 일치시켜야 합니다.

## 1. 처리하는 정보와 목적

### 기기 안에만 저장하는 정보

앱은 아래 정보를 기기 내 앱 저장소에 저장합니다.

| 정보 | 목적 | 보관 |
| --- | --- | --- |
| 선택한 학교명, 교육청 코드, 학교 코드, 학교 종류 | 급식·시간표·일정 조회 | 학교 변경, 앱 데이터 삭제 또는 앱 삭제 시까지 |
| 학년·반 | 해당 학급 시간표 조회 | 학교 변경, 앱 데이터 삭제 또는 앱 삭제 시까지 |
| 타이머 설정·진행 상태, 텔레메트리 동의 여부 | 타이머 복원 및 선택 동의 적용 | 사용자가 초기화하거나 앱 데이터를 삭제할 때까지 |

앱은 계정, 이름, 생년월일, 전화번호, 이메일 주소, 광고 ID, Android ID, 기기 일련번호를 수집하거나 요구하지 않습니다.

### 학교 정보 조회

이용자가 학교·학년·반을 저장하고 급식·시간표·학사 일정을 조회하면, 앱은 교육부/교육청의 나이스 교육정보 개방 포털 API에 조회에 필요한 학교·교육청 코드, 날짜 및 시간표 조회를 위한 학년·반 정보를 전송합니다. 이 정보는 선택한 정보를 조회하는 목적 외에 사용하지 않습니다.

### 선택 동의: 이용 정보 분석

이용자가 `이용 정보 분석에 동의`를 켠 경우에만 Firebase Analytics로 다음의 제한된 정보를 전송합니다.

- 앱 진입 및 화면·기능 이용, 시간표·급식·일정 조회 결과, 타이머 동작
- 조회 성공/실패, 데이터 출처(네트워크/캐시), 처리 시간, 정규화된 오류 코드
- 교육청 코드, 학교 코드, 학교 종류, 초기 설정 완료 여부
- 앱 실행 환경(릴리스/QA 등)

학교명, 학년, 반, 학교 검색어, API URL·응답 본문은 Analytics 이벤트로 전송하지 않습니다. 광고 저장소·광고 개인화·광고 사용자 데이터 수집은 사용하지 않습니다.

### 선택 동의: 오류 진단

이용자가 `오류 진단 정보 제공에 동의`를 켠 경우에만 Firebase Crashlytics로 비정상 종료 및 제한된 비치명 오류 정보를 전송합니다. 이때 앱 버전, 제조사, 기기 모델, Android SDK 버전, 현재 화면, 교육청/학교 코드, 학교 종류, 초기 설정 완료 여부, 정규화된 오류 코드 및 기술적 오류 스택이 포함될 수 있습니다.

## 2. 제3자 제공 및 처리 위탁

앱은 판매·광고 목적의 제3자 제공을 하지 않습니다. 서비스 제공을 위해 아래 외부 서비스를 사용합니다.

| 수탁·제공처 | 처리 목적 | 관련 정보 |
| --- | --- | --- |
| 나이스 교육정보 개방 포털 API | 급식·시간표·학사 일정 조회 | 학교/교육청 코드, 조회 날짜, 시간표 조회용 학년·반 |
| Google Firebase (Analytics, Crashlytics) | 이용 분석 및 오류 진단 | 각 선택 동의 항목에 적힌 정보 |

Firebase 서비스의 처리 방식은 [Google 개인정보처리방침](https://policies.google.com/privacy) 및 [Firebase 데이터 처리 정보](https://firebase.google.com/support/privacy)를 따릅니다. Firebase는 서비스 제공 과정에서 네트워크·기술적 로그를 자체 정책에 따라 처리할 수 있습니다.

## 3. 선택 동의와 철회

Analytics와 오류 진단은 기본적으로 꺼져 있으며, 동의하지 않아도 학교 정보 조회와 타이머의 핵심 기능을 사용할 수 있습니다. 이용자는 언제든지 앱의 **설정 → 선택 정보 수집 동의**에서 각각 켜거나 끌 수 있습니다.

- Analytics를 끄면 앱은 분석 데이터 수집을 중지하고 앱에 보관된 Analytics 식별·기본 이벤트 데이터를 초기화하도록 요청합니다.
- 오류 진단을 끄면 이후 진단 정보 수집을 중지하고, 전송되지 않은 오류 보고서를 삭제하도록 요청합니다.

이미 Firebase에 전송되어 보관 중인 정보의 삭제·보관은 Firebase Console 설정 및 Google 정책의 적용을 받을 수 있습니다.

## 4. 보관 및 파기

기기 내 정보는 이용자가 학교를 변경하거나 앱 데이터 삭제·앱 삭제를 하면 삭제됩니다. Firebase에 선택적으로 전송된 정보의 보관 기간은 운영자가 Firebase Console에서 설정한 기간 및 Google 정책에 따릅니다. 운영자는 출시 전 이 기간을 확정하고 이 방침에 반영합니다.

## 5. 이용자의 권리와 문의

이용자는 앱 설정에서 선택 동의를 변경할 수 있고, Android 설정에서 앱 데이터 삭제 또는 앱 삭제로 기기 내 저장 정보를 삭제할 수 있습니다. 개인정보 처리에 관한 문의, 열람·정정·삭제 요청은 위 문의처로 보내 주세요.

## 6. 아동·청소년 이용자

앱은 학생이 사용하기 쉬운 학교 정보 확인 도구입니다. 민감정보 또는 계정 기반 개인 프로필을 수집하지 않으며, 선택형 분석·진단 수집은 기본적으로 꺼져 있습니다. 보호자 또는 법정대리인의 권리 행사 문의는 위 문의처로 할 수 있습니다.

## 7. 방침 변경

이 방침이 변경되면 시행일과 변경 내용을 공개 페이지 및 앱 업데이트 안내에 표시합니다.
